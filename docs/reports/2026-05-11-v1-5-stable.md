# v1.5.0 stable — Time-travel

Date: 2026-05-11

Promotes v1.5.0-rc1 to stable. Closes the most consequential deferred
items from the rc review: `runs/search?as_of`, UI date-picker, events
retention janitor, replay-row cap (DoS defense), and future-`as_of`
rejection.

## What this pass closed

### From v1.5.0-rc1 review (deferred items)

| ID | Severity | Issue | Status |
|----|----------|-------|--------|
| —  | scope    | `runs/search?as_of` (the search loop was passing `asOf=0`) | **fixed** — SearchRuns now parses `?as_of`, filters out runs whose `start_time > as_of`, and reconstructs each surviving run via `GetRunAsOfInWorkspace`. Test: `TestTimeTravelSearchRunsAsOf`. |
| —  | scope    | UI date-picker on the run detail page | **fixed** — `_renderTimeTravelBar` on the run page reads/writes `?as_of=<ms>` on the hash and uses a native `<input type="datetime-local">` picker with `max=now`. A snapshot banner indicates when the view is historical. |
| M3 | medium   | Unbounded event-row scan in `GetRunAsOf` | **fixed** — `MaxEventsPerReplay = 50_000` cap with `LIMIT N+1` overflow detection. Returns `ErrReplayLimitExceeded`. Test: `TestEventsReplayLimitExceeded`. |
| M4 | medium   | No TTL / cleanup for the events table | **fixed** — new `Store.PruneEventsBefore` + janitor sweep gated on `LITEMLFLOW_EVENTS_RETENTION` (default 0 = unlimited). Test: `TestEventsPruneBeforeRemovesOlderRows`. |
| M1 | medium   | Future `as_of` silently aliased to "now" | **fixed** — `parseAsOf` rejects timestamps more than 60s past `time.Now()`. Test: `TestTimeTravelFutureAsOfRejected`. |
| —  | hygiene  | `runs/search` cross-workspace exposure under `?as_of` | already enforced via `GetRunAsOfInWorkspace`; documented in the SearchRuns godoc. |

## Wire-level summary

- `GET /api/2.0/mlflow/runs/get?as_of=<unix_ms>` — unchanged from rc.
- `GET /api/2.0/mlflow/metrics/get-history?as_of=<unix_ms>` — unchanged from rc.
- **NEW**: `POST /api/2.0/mlflow/runs/search?as_of=<unix_ms>` — search loop reconstructs every returned run at T.
- **NEW**: `GET /api/v1/runs/{id}/data?as_of=<unix_ms>` — native run-detail bundle reconstructs at T (UI date-picker uses this).
- All `?as_of` paths reject 0 / negative / non-integer / >now+60s with HTTP 400.

## Config

- `LITEMLFLOW_EVENTS_RETENTION` (duration string, e.g. `720h` for 30 days; default empty = unlimited) — when set, the janitor sweep deletes event rows older than this on each tick. Tradeoff: pruned rows are lost from the replay history, so any `?as_of=T` for T before `now-retention` will over-report tag presence.
