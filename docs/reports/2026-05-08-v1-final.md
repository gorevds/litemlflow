## Delivery

### Self-pen-test (as substitute for paid pen test)

Three Go-ecosystem scanners + manual threat-model walkthrough. Documented in `docs/security-audit.md`.

| Tool | Coverage | Output |
|---|---|---|
| **govulncheck** | stdlib + dep CVEs that are *actually called* by our code | 4 found, all fixed |
| **gosec** | static patterns: SQL concat, weak hashes, file modes, integer overflow, … | 46 → 38 raw findings; 6 fixed; 29 documented as false positives in CI accept-list |
| **semgrep** | `p/security-audit + p/golang` rulesets | 4 found; 1 real (open redirect, fixed); 3 dups with gosec |
| **gremlins** | mutation testing | baselines: auth 89%, store 75%, webhooks 53% |

**Real bugs fixed:**

| ID | Where | Fix |
|---|---|---|
| GO-2026-4982 / 4980 | `html/template` XSS | Go toolchain 1.26.3 |
| GO-2026-4971 | `net.Dialer` NUL panic | Go 1.26.3 |
| GO-2026-4918 | HTTP/2 transport infinite loop | `x/net` v0.53.0 |
| open-redirect | OIDC `return_to` accepted `//evil.com`, CRLF, NUL | new `safeReturnTo` + `TestSafeReturnTo` |
| G110 | gzip bomb in `litemlflow restore` | `io.LimitReader` 200 GiB cap |
| G118 | session-touch goroutine never timed out | `context.WithTimeout(5s)` |
| G301-306 | dir 0o755, file 0o644 | dirs 0o750, artifacts 0o640, internal 0o600 |

**Accepted false positives (29 entries)** locked into a CI gate (`.github/scripts/check_gosec.py`). Each entry has a one-line justification. New HIGH findings outside the accept-list fail the build until either fixed or added with rationale.

### Mutation testing baseline

`gremlins` measured how good our tests are at killing synthetic bugs:

| Package | Killed | Lived | Not covered | Timed out | Efficacy | CI threshold |
|---|---|---|---|---|---|---|
| `internal/auth` | 59 | 7 | 8 | 4 | **89.39%** | 80% |
| `internal/store` | 365 | 124 | 120 | 3 | **74.64%** | 70% |
| `internal/webhooks` | 16 | 14 | 26 | 11 | **53.33%** | 50% |

Auth + store are the security-critical layers and have strong baselines. Webhooks deserves more dispatch tests; flagged for a v1.1 patch.

### Kind cluster CI

`.github/workflows/kind.yml`:
1. Builds `litemlflow:ci` and `litemlflow-operator:ci` images.
2. Spins up kind via `helm/kind-action@v1`.
3. Loads images (server tagged as `ghcr.io/gorevds/litemlflow:ci` so the operator finds it).
4. Applies CRD + RBAC + manager. Patches deployment to use the loaded operator image.
5. Creates `LiteMLflow` CR (`operator/config/samples/litemlflow_v1alpha1_litemlflow.yaml`).
6. Waits for the pod readiness gate, then `kubectl exec` to hit `/healthz` from inside.

Also added the missing `operator/Dockerfile` (distroless static, pure Go).
